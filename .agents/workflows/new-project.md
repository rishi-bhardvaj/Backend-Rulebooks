# Workflow: New Project

1. Inspect repository/toolchain and identify application entry point.
2. Read applicable rules and deployment constraints.
3. Write architecture and requirements plan.
4. Establish configuration, persistence, migrations, error contract, observability, and test strategy before feature sprawl.
5. Implement incrementally.
6. Build and start the application.
7. Exercise at least one real request through each critical boundary.
8. Add negative/security tests before declaring auth or authorization complete.
9. Run regression, dependency, secret, and production-readiness checks.
10. Produce the verification report. Mark unknowns NOT VERIFIED/BLOCKED.
