# Workflow: Production Audit

Verify build reproducibility, runtime startup, configuration, migrations, health/readiness, auth, authorization, validation, error handling, observability, dependency/security scans, secret scanning, rate limits, CORS/headers, external dependencies, graceful shutdown, backups/recovery, deployment, rollback, and regression tests.

Separate VERIFIED evidence from assumptions. Any unavailable production dependency or unexecuted deployment step is NOT VERIFIED/BLOCKED.
