# Workflow: Implement API

1. Define endpoint contract and authorization rule.
2. Inspect route registration and middleware conventions.
3. Implement validation, business logic, persistence, and error mapping.
4. Register the route in the real application.
5. Build and start the service.
6. Test success, malformed input, missing/invalid auth, unauthorized resource access, not found, conflict, and dependency failure as applicable.
7. Verify database side effects and frontend/network contract if a client exists.
8. Add automated regression/API tests and report evidence.
