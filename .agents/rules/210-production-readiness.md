# Production Readiness

Before release, verify applicable: build reproducibility; runtime startup; configuration; migrations; health/readiness; authentication; authorization; input validation; error handling; observability; dependency security; rate limits; CORS/headers; backups/recovery; graceful shutdown; deployment/rollback; external integrations; and regression tests.

A missing environment, unavailable production dependency, or unexecuted deployment validation is a blocker or explicit NOT VERIFIED state, not a reason to invent confidence.
