# API Checklist

- [ ] Method/path registered in real application
- [ ] Auth requirement explicit
- [ ] Authorization requirement explicit
- [ ] Request schema and boundary validation
- [ ] Success contract/status
- [ ] Error contract/statuses
- [ ] Not found/conflict behavior
- [ ] Pagination/filter/sort limits where applicable
- [ ] Idempotency/concurrency behavior where applicable
- [ ] Real HTTP verification
- [ ] Negative/security tests
- [ ] Persistence side effects verified
- [ ] Frontend/network contract verified when applicable
