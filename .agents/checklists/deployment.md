# Deployment Checklist

- [ ] Reproducible build
- [ ] CI tests and security checks
- [ ] Secrets/configuration validated
- [ ] Migrations executable
- [ ] Health/readiness checks
- [ ] Graceful shutdown
- [ ] Runtime environment verified
- [ ] External dependencies configured
- [ ] Backup/recovery strategy
- [ ] Rollback strategy
- [ ] Post-deploy smoke/API verification
- [ ] Logs/metrics/error tracking available
- [ ] No production-only assumptions remain unverified
